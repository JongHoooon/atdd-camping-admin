# 회전 기록

4단계(acceptance-criteria → acceptance-test → implementation → verdict) 스킬 중 하나가
같은 실패를 세 번 반복하는 동안, 각 시도마다 무엇을 했는지 한 줄씩 남긴다(최대 3줄). 세 번째도
실패하면 멈추고 사람을 부른다. 정상적으로 완료됐을 때는 남기지 않는다 — 이건 완료 기록이
아니라 반복 실패 과정을 사람에게 넘길 때 보여주는 기록이다. 자동으로 검사되는 게이트는 아니다.

형식: `<시각> <티켓> <스킬>: <몇 번째 시도인지, 무엇을 했다가 어떻게 실패했는지>`
